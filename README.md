# E-Commerce ETL Pipeline 🚀

An automated data pipeline built with Apache Airflow to process 541K real e-commerce transactions.

## Tech Stack
Python | Apache Airflow | Pandas | SQLite | GitHub Codespaces

## Pipeline Steps
- **Extract** → 541,909 raw transactions from UCI Online Retail dataset
- **Transform** → Clean & process → 392,692 quality rows
- **Load** → 4 structured tables in SQLite
- **Validate** → Automated data quality checks

## Dataset
[UCI Online Retail Dataset](https://www.kaggle.com/datasets/carrie1/ecommerce-data) via Kaggle
